### Added
- Project scaffold and core runtime: persistent per-save system (`CyberbaneSystem`),
  global cross-save service (`CyberbaneService`), internal event bus, logging, versioned
  config, shared types/enums, Mod Settings integration, and the Codeware localization provider.

_Cyberbane is in active development and has not had a public release yet._
